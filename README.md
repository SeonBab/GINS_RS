## 프로젝트 소개

`GINS_RS`는 로스트아크와 아이온2 같은 MMO 레이드의 **기믹 암기형 보스전**을 단일 스테이지 규모로 구성한 프로젝트입니다.
플레이어는 우클릭으로 캐릭터를 이동시키고, 공격·대시·스킬을 활용해 보스의 일반 패턴과 암기 기믹에 대응합니다.

### 김선국 — 프로그래밍

C++ 기반 게임플레이 프로그래밍 전반을 담당했습니다.
Gameplay Ability System을 중심으로 플레이어 전투와 보스 페이즈·패턴을 구현하고, 공격 예고·판정·피격 반응부터 UI, 입력, 상호작용과 게임 흐름까지 각 시스템을 연결했습니다. 또한 기능별 자동화 테스트를 작성하고 빌드 검증을 수행해 핵심 게임 규칙을 반복해서 확인할 수 있는 기반을 마련했습니다.

## 핵심 게임플레이

- **클릭 이동 기반 전투**: 우클릭으로 목적지를 지정하고 보스의 공격 범위와 안전지대를 빠르게 오갑니다.
- **패턴 학습과 대응**: 공격 예고를 보고 피하는 일반 패턴과, 순서·안전 구역을 기억해야 하는 암기 기믹을 공략합니다.
- **공격과 회피 선택**: 기본 공격과 세 가지 스킬로 피해를 주고, 대시로 이동 압박에 대응합니다.
- **한 번의 도전**: 전투 중 부활 없이 하나의 목숨으로 보스를 처치해야 하며, 실패하면 전투를 다시 시작합니다.

### 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 우클릭 | 지정 위치로 이동 |
| 마우스 좌클릭 / `Q` | 기본 공격 |
| `Space` | 대시 |
| `W` / `E` / `R` | 스킬 사용 |
| `G` | 상호작용 |
| `Esc` | 인게임 메뉴 열기·닫기 |
